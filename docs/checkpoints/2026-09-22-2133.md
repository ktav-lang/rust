## Decisions

- **rust's tools/docs-gen was fully replaced, not kept alongside polydoc.**
  It served the same purpose (parallel multilingual markdown from source
  units) with an incompatible unit model; keeping both would mean two ways to
  generate the same files. Deleted outright once byte-identity was proven.
- **The 37 docs-gen source files map 1:1 to 37 polydoc units**, not merged
  further or split finer — proven safe by checking every file's first unit is
  block-joined in all three languages before committing to this mapping.
- **CONTRIBUTING/SECURITY move to root-docs/ now, not deferred** — the user's
  explicit "fix everything" after the review covered these, even though they
  were never part of the original docs-gen migration's scope.
- **`v0.8.0` tag deleted after the accidental early push+cancel**, rather than
  left in place to be moved later — avoids a tag that doesn't point at the
  final intended release commit.
- **SECURITY's supported-version line uses `@@MINOR_LINE@@`** (derived from
  `Cargo.toml` at build time) instead of a hand-written string, specifically
  so this exact staleness class (found independently in both spec and rust
  this session) cannot recur silently.
